ANVESHA — Tamil Nadu SCRB DATASET PACKAGE

Values only. Page text and prose are excluded.

Source years represented:
2017, 2018, 2019, 2020, 2022, 2023.

Core files:
- ALL_SCRB_VALUES_LONG.csv : one numeric/raw value per row
- ALL_SCRB_VALUES_WIDE.csv : one source table row per row, metric_1...metric_N
- TABLE_CATALOG.csv : source table titles
- DATASET_REGISTRY.csv : generated dataset inventory

Category files:
IPC, SLL, women, children, arrests, disposal, cybercrime, economic offences,
missing persons, murder, property crimes, road accidents, SC, ST, suicides,
human trafficking.

IMPORTANT:
The SCRB reports use different multi-level headers across tables. Therefore
metric_1, metric_2, etc. retain the source column order but are NOT globally
assigned semantic meanings. TABLE_CATALOG.csv identifies the exact source table.
No individual-level records or relationships have been fabricated.
