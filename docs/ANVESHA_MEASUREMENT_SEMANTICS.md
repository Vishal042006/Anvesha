# ANVESHA Measurement Semantics Audit Report

**Date:** September 30, 2026  

### Measurement Type Rules Enforced:
1. **INCIDENT_COUNT:** Strictly IPC and SLL criminal offence counts. Approved for `crime_count` forecasting target.
2. **MONETARY_VALUES:** Rupee values stolen/recovered quarantined from target.
3. **ARREST_COUNTS:** Quarantined to `fact_arrest` table.
4. **DISPOSAL_STATISTICS:** Quarantined to `fact_police_disposal` and `fact_court_disposal` tables.
5. **VICTIM_COUNTS:** Quarantined to `fact_victim` table.
